# Хатшының АЖО (Авторизация және Рөлдер жүйесімен)

## VS Code арқылы іске қосу:
1. ZIP мұрағатты ашып, ішіндегі `ARM_Hatshy_Kaz_v2` қалтасын VS Code-та ашыңыз (`File -> Open Folder...`).
2. Терминалда (`Ctrl + ~`) іске қосыңыз:
   ```bash
   pip install flask
   python app.py
   ```
3. Браузерде **`http://127.0.0.1:5000`** ашыңыз.

## Дайын аккаунттар:
- **Кафедра хатшысы:** логин `hatshy`, құпиясөз `1234` (тек кафедра деректерімен жұмыс істейді).
- **Сайт басқарушысы (Админ):** логин `admin`, құпиясөз `admin` (кафедра деректеріне қоса **Пайдаланушылар (Рөлдер)** бөлімі арқылы жаңа аккаунттар қосып, өшіре алады).
